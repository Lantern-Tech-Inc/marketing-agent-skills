# Query types, formats, titles, and funnel stages

Canonical classification used by every Lantern content and research skill. Classify before outlining, briefing, or prioritizing. When a query fits more than one type, pick the type that matches the format currently winning the live results and note the secondary type.

## Query type classification

| Query type | Typical signals | What the reader needs |
| --- | --- | --- |
| Informational / FAQ | what is, why, does, can, meaning | A direct definition or answer, then context |
| Comparison | vs, versus, alternative, compare, difference, better | Criteria, side-by-side evidence, a fair verdict by use case |
| Cost / pricing | cost, price, how much, fee, budget, worth it | Ranges, cost drivers, dated sources, what changes the price |
| Process / how-to | how to, steps, set up, guide, checklist | Ordered steps, prerequisites, time, common mistakes |
| Seasonal / temporal | year, month, season, deadline, "this year", event names | Dated guidance grouped by period, review date |
| Listicle | best, top, examples, ideas, tools | Selection criteria, scannable entries, honest trade-offs |

## Format and title mapping

| Query type | Primary page format | Title pattern (examples) |
| --- | --- | --- |
| Informational / FAQ | Answer-first section, definition box, FAQ | "What Is X? Definition, Examples, and How It Works" |
| Comparison | Comparison table plus per-criterion sections | "X vs Y: Key Differences and Which to Choose" |
| Cost / pricing | Cost table with ranges, drivers, date of data | "How Much Does X Cost in [Year]? Price Ranges and Factors" |
| Process / how-to | Numbered steps, prerequisites, time estimate | "How to X: [N] Steps [Outcome]" |
| Seasonal / temporal | Sections grouped by period, dated | "X in [Month/Season Year]: What to Know" |
| Listicle | Numbered entries with criteria and trade-offs | "[N] Best X for [Audience/Use Case] in [Year]" |

Title and meta rules:

- Put the primary query, or its closest natural phrasing, near the start of the title.
- Aim for a title that fits in about 50–60 characters so it is less likely to be truncated. Google may rewrite title links; write for clarity, not tricks.
- Only include a year or a number when the content actually supports it and will be maintained.
- The H1 and title must agree in substance. They may differ in wording.
- Meta description: about 155 characters or fewer, previews the specific answer, and does not repeat the title verbatim. Google may generate its own snippet.

## Funnel (awareness) stages

Use these to decide how much the page should explain versus persuade.

| Stage | Reader state | Content implication |
| --- | --- | --- |
| Unaware | Does not recognize the problem yet | Lead with symptoms and consequences, not the product |
| Problem aware | Knows the problem, not the solutions | Explain causes and solution categories |
| Solution aware | Knows solution types, comparing approaches | Criteria, comparisons, trade-offs |
| Product aware | Knows the brand or product, evaluating it | Proof, pricing, objections, alternatives |
| Most aware | Ready to act | Clear offer, next step, friction removal |

## AI prompt types

Conversational prompts people put to AI assistants. Use them alongside classic keywords. They are a qualitative demand signal unless they are measured.

| Prompt type | Example |
| --- | --- |
| Recommendation | "What is the best [category] for [audience]?" |
| Comparison | "[Brand A] vs [Brand B] for [use case]" |
| Validation | "Is [brand] legit / worth it / reliable?" |
| How-to | "How do I [task] with [category]?" |
| Cost | "How much does [category] cost for [size/context]?" |
| Definitional | "What is [concept] and how does it work?" |
| Reputation (competitive) | "[brand] complaints", "[brand] alternatives" |
